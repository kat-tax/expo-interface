# expo-interface

A native-first, universal UI kit for [Expo](https://expo.dev) built on
[`@expo/ui`](https://docs.expo.dev/versions/v57.0.0/sdk/ui/).

- Every component renders the platform's own control: **SwiftUI** on iOS,
  **Jetpack Compose** (Material 3) on Android and a **real DOM** element on web.
- A single accent color seeds the theme on every platform.
- Screens follow the system light or dark scheme without per-platform styling.

This site is the web build of the kit's Storybook: each entry under
**Components** and **Layout** documents one export, lists its props and
renders the web implementation live. The iOS and Android controls render in
the on-device Storybook (see [Development](?path=/docs/guides-development--docs)).

## Install

```sh
npx expo install expo-interface @expo/ui @expo/material-symbols
```

The components are built on standard Expo modules, which are peer
dependencies. Most Expo Router apps already have them; if any are missing:

```sh
npx expo install expo-router expo-symbols expo-image expo-constants expo-status-bar expo-system-ui expo-web-browser react-native-safe-area-context
```

Jetpack Compose draws icons from XML vector drawables, which
`@expo/material-symbols` provides. Register the extension in `metro.config.js`:

```js
const {getDefaultConfig} = require('expo/metro-config');
const config = getDefaultConfig(__dirname);
config.resolver.assetExts.push('xml');
module.exports = config;
```

## Setup

### 1. Wrap the app in `AccentProvider`

`seed` is any hex color; the default is `#007AFF`.

```tsx
// app/_layout.tsx
import {ThemeProvider, Stack} from 'expo-router';
import {AccentProvider, useNavTheme} from 'expo-interface';

function Navigation() {
  return (
    <ThemeProvider value={useNavTheme()}>
      <Stack screenOptions={{headerShown: false}}/>
    </ThemeProvider>
  );
}

export default function Layout() {
  return (
    <AccentProvider seed="#8959EA">
      <Navigation/>
    </AccentProvider>
  );
}
```

### 2. Emit the palette on web

On web the colors are CSS custom properties, emitted once from the root HTML.

```tsx
// app/+html.tsx
import {ScrollViewStyleReset} from 'expo-router/html';
import {getThemeCSS} from 'expo-interface';

export default function Root({children}: React.PropsWithChildren) {
  return (
    <html lang="en">
      <head>
        <meta charSet="utf-8"/>
        <meta name="viewport" content="width=device-width, initial-scale=1"/>
        <style dangerouslySetInnerHTML={{__html: getThemeCSS()}}/>
        <ScrollViewStyleReset/>
      </head>
      <body>{children}</body>
    </html>
  );
}
```

### 3. Build screens

```tsx
import {Screen, FieldGroup, Switch, Button} from 'expo-interface';

export default function Home() {
  return (
    <Screen native>
      <FieldGroup>
        <FieldGroup.Section title="Sync">
          <Switch label="Notifications" value={on} onValueChange={setOn}/>
          <Button label="Continue" onPress={save}/>
        </FieldGroup.Section>
      </FieldGroup>
    </Screen>
  );
}
```

## Components

Everything is exported from `expo-interface`. Value controls are controlled:
pair `value` with `onValueChange`. Web overlays use the Popover API, CSS
anchor positioning and `<dialog>`.

| Component | Description | iOS | Android | Web |
| --- | --- | :-: | :-: | :-: |
| [Screen](?path=/docs/layout-screen--docs) | Screen container that handles safe areas, status bar, background and content width, optionally hosting native content | ✓ | ✓ | ✓ |
| [ScreenHeader](?path=/docs/layout-screenheader--docs) | Simple header bar with an optional back button and a trailing slot | ✓ | ✓ | ✓ |
| Tabs | Tab bar for `expo-router`: native tabs on iOS and Android, a floating top bar with a logo on web | ✓ | ✓ | ✓ |
| TabStack | Preconfigured `expo-router` stack for the root screen of a tab | ✓ | ✓ | ✓ |
| ConstrainedStackHeader | Stack header that matches the content max-width on web | | | ✓ |
| [Sheet](?path=/docs/components-sheet--docs) | Bottom sheet that inherits the accent color | ✓ | ✓ | ✓ |
| [FieldGroup](?path=/docs/components-fieldgroup--docs) | Scrollable settings form made of titled sections of rows | ✓ | ✓ | ✓ |
| [ListItem](?path=/docs/components-listitem--docs) | Tappable row with leading, trailing and supporting text slots | ✓ | ✓ | ✓ |
| [Collapsible](?path=/docs/components-collapsible--docs) | Row that expands and collapses its content | ✓ | ✓ | ✓ |
| [Divider](?path=/docs/components-divider--docs) | Horizontal or vertical hairline separator | ✓ | ✓ | ✓ |
| [Button](?path=/docs/components-button--docs) | Filled, outlined or text button with optional icons, sizes, shapes and a destructive role | ✓ | ✓ | ✓ |
| [TextField](?path=/docs/components-textfield--docs) | Single or multiline text input with keyboard type, capitalization and secure entry | ✓ | ✓ | ✓ |
| [Switch](?path=/docs/components-switch--docs) | On/off toggle with a leading label | ✓ | ✓ | ✓ |
| [Checkbox](?path=/docs/components-checkbox--docs) | Checked/unchecked box with a leading label | ✓ | ✓ | ✓ |
| [Slider](?path=/docs/components-slider--docs) | Thumb dragged along a continuous or stepped range | ✓ | ✓ | ✓ |
| [Stepper](?path=/docs/components-stepper--docs) | Number adjusted with increment and decrement buttons | ✓ | ✓ | ✓ |
| [Picker](?path=/docs/components-picker--docs) | Dropdown that selects one option from a list | ✓ | ✓ | ✓ |
| [SegmentedControl](?path=/docs/components-segmentedcontrol--docs) | Row of segments that selects one option | ✓ | ✓ | ✓ |
| [DateTimePicker](?path=/docs/components-datetimepicker--docs) | Picks a date, a time or both, with optional bounds | ✓ | ✓ | ✓ |
| [Progress](?path=/docs/components-progress--docs) | Linear bar or circular ring, determinate or indeterminate | ✓ | ✓ | ✓ |
| [Menu](?path=/docs/components-menu--docs) | Dropdown menu of actions opened from a button | ✓ | ✓ | ✓ |
| [ContextMenu](?path=/docs/components-contextmenu--docs) | Menu of actions opened by long-pressing (or right-clicking) its content | ✓ | ✓ | ✓ |
| [Tooltip](?path=/docs/components-tooltip--docs) | Short hint shown on hover, focus or long-press; an accessibility hint on iOS | | ✓ | ✓ |
| [Alert](?path=/docs/components-alert--docs) | Modal dialog or action sheet with a title, message and actions | ✓ | ✓ | ✓ |
| [QRCode](?path=/docs/components-qrcode--docs) | Renders a value as a QR code image | ✓ | ✓ | ✓ |
| ExternalLink | Link that opens in an in-app browser on native and a new tab on web | ✓ | ✓ | ✓ |
| [Typography](?path=/docs/components-typography--docs) | Text in the platform type scale, with `Title`, `Body`, `Caption` and other variants as shortcuts | ✓ | ✓ | ✓ |

The router-bound exports (`Tabs`, `TabStack`, `ConstrainedStackHeader`,
`ExternalLink`) need an `expo-router` navigator around them, so they have no
story here; see the [example app](https://github.com/kat-tax/expo-interface/tree/master/example).
